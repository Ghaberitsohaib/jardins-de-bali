# Superpowers Engineering Rules & Quality Standards

When working on this codebase:

## 1. Core Engineering Discipline (Superpowers)
- **Systematic Debugging**: When diagnosing an issue, never guess or apply random patches. Formulate hypotheses, isolate root causes, verify with test scripts/screenshots, and fix cleanly.
- **Verification Before Completion**: Never declare a task complete without rigorous verification. Run tests, verify responsiveness, inspect pixel integrity (including DPR 2.0+), and confirm zero build or runtime errors.
- **Planning & Execution**: For complex features, outline steps clearly before execution.

## 2. Luxury Aesthetic & UI Integrity
- **Color Harmony**: Imperial Dark `#10150F`, Champagne Gold `#C5A880`, Warm Lin `#FDFBEF`.
- **Zero Artifacts**: No visible seams, no subpixel line glitches, proper z-indexing, fluid GSAP/Lenis animations.
- **Mobile First & Responsive**: Ensure 100% responsiveness on mobile screens (375px–430px) as well as wide desktops.

## 3. Git & Code Cleanliness
- Keep commits structured, clean, and tested.
- Remind daily push to GitHub (`https://github.com/Ghaberitsohaib/jardins-de-bali`).
