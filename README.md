# Jardins de Bali — Menara Marrakech 🌿🏛️

> Vitrine immobilière et commerciale de prestige au cœur de Marrakech (Boulevard M-16, Menara).

## ✨ Présentation du Projet

**Jardins de Bali** est un complexe immobilier et commercial exclusif situé sur le Boulevard M-16 à Marrakech, alliant architecture contemporaine raffinée, art de vivre d'exception et espaces d'affaires haut de gamme.

### 🌟 Caractéristiques Principales
- **Espaces Commerciaux & Retail** : 4 Flagship Stores en rez-de-chaussée avec vitrines panoramiques sur voie passante, mezzanines showrooms et 12 plateaux de bureaux modulables.
- **Résidences & Duplex** : Appartements de luxe et duplex d'exception avec terrasses panoramiques offrant une vue imprenable sur les montagnes de l'Atlas.
- **Expérience Immersive 3D** : Maquette interactive 3D, exploration des plans d'étages et visites virtuelles.
- **Animations & Performance** : Interface haut de gamme propulsée par GSAP ScrollTrigger et Lenis Smooth Scroll.

---

## 🛠️ Stack Technique

- **Bundler & Build Tool** : [Vite](https://vitejs.dev/)
- **Animations & Micro-interactions** : [GSAP 3](https://greensock.com/gsap/) (ScrollTrigger, TweenLite)
- **Rendu 3D & Visualisation** : [Three.js](https://threejs.org/)
- **Smooth Scrolling** : [Lenis](https://lenis.darkroom.engineering/)
- **Style & Design System** : CSS modulaire luxury design (palette vert impérial `#10150F`, or champagne `#C5A880`, lin `#FDFBEF`).

## 🚀 Installation & Développement

```bash
# Cloner le dépôt
git clone https://github.com/Ghaberitsohaib/jardins-de-bali.git

# Accéder au dossier
cd jardins-de-bali

# Installer les dépendances
npm install

# Lancer le serveur local de développement
npm run dev

# Compiler pour la production
npm run build
```
